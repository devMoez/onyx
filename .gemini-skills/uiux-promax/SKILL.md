# UI/UX ProMax

## The Aesthetic Anchor Framework
Before generating code, select one of these anchors to lock in design tokens:

- **Swiss**: Pure white, Helvetica/Söhne, 1px borders, International Orange accents. Focus on grid and typography.
- **Aurora**: Dark saturated backgrounds, mesh gradients, neon highlights, glassmorphism.
- **Organic**: Earth tones, large border-radius, subtle grain, humanist serifs (e.g., Inter + Playfair Display).
- **Brutalist**: Primary colors, hard 4px/8px offset shadows (Neo-brutalism), thick borders, monospaced fonts.
- **Retro-Future**: Pitch black, green/amber mono text, CRT scanlines, subtle chromatic aberration.

## Core Design Principles

### 1. Visual Hierarchy
- Use scale, weight, and color to guide the eye.
- Primary actions must be unmistakable.
- Maximum 3 font sizes per view (Small, Base, Title).

### 2. Spacing & Rhythm
- Use a strict 4px/8px grid system.
- Generous white space is a sign of luxury/professionalism.
- Keep consistent padding within cards and containers.

### 3. Feedback & State
- Every interaction must have a state (Hover, Active, Loading, Success, Error).
- Use subtle transitions (150ms-300ms) for all color/scale changes.

### 4. Content-First
- Design for real data, not "Lorem Ipsum".
- Ensure high contrast for readability (WCAG AA standard).
