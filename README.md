# 🖤 ONYX — Personal AI

Your system. Your rules. Your AI.

Forked from [OpenClaw](https://github.com/openclaw/openclaw). MIT License.

## Features
- **Desktop Control** — mouse, keyboard, screen, windows, processes
- **Live Screen View** — real-time MJPEG stream of your desktop
- **Persistent Memory** — every session logged, searchable
- **Voice Control** — talk to Onyx (coming soon)
- **Autonomy Loop** — Onyx plans, executes, and verifies (coming soon)
